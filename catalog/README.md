# Catalog submission

Ready-to-copy entry for the community plugin catalog
[awesome-dsh-plugin](https://github.com/awesome-dsh-plugin/awesome-dsh-plugin#contributing),
which also feeds the **Plugins → Discover** tab of the DSH web GUI and
[dsh-market](https://github.com/dsh-market/dsh-market).

`uptick7__dsh-plugins.yml` is the whole submission: open a PR to that repository adding the file as `data/plugins/uptick7__dsh-plugins.yml`. Nothing else is required — the READMEs and the market index are regenerated automatically after merge.

## Before opening the PR

- [ ] The plugin is installable, i.e. `package.json` declares the `dsh.bundle` manifest (checked automatically on every PR).
- [ ] The GitHub repository has the topic `dsh-plugin` (repository page → About → gear icon → Topics).
- [ ] The repository is at least 1 day old.
